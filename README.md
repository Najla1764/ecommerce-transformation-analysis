# E-Commerce Business Transformation Analysis

## Objective
Identify top processes in e-commerce operations where AI and automation
can reduce manual effort, errors, and costs.

## Business Problem
E-commerce companies like Flipkart and Amazon India handle millions of
daily operations manually — leading to high error rates, delays, and costs.

## What This Project Does
- Analyzes 10 core e-commerce processes across 50 data points
- Scores each process on automation potential and ROI
- Generates automated Excel report with 3 sheets
- Visualizes findings through a dashboard with 3 charts

## Key Findings
- Fraud Detection: highest error rate (25-30%), needs immediate automation
- Inventory Management: highest manual hours wasted
- Payment Reconciliation: high error rate, fully automatable

## Tools Used
Python | Pandas | Matplotlib | OpenPyXL | Excel | Google Sheets

## Files
- data/ — raw dataset (50 records, 10 processes)
- analysis/ — Python analysis script
- output/ — auto-generated Excel report
- dashboard/ — visualisation charts
